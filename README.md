# 社交媒体平台用户分析 —— 2025 五一数学建模竞赛 C 题

> **五一数学建模竞赛 二等奖** ｜ 第二十二届 ｜ 本科组

某社交媒体平台需要深入分析用户与博主之间的互动行为，据此预测用户行为并优化内容推荐。
本题给了两批数据：附件 1 是 2024.7.11–7.20 的用户行为记录，附件 2 是 7.22 当天的
观看 / 点赞 / 评论记录。四个问题分别要求做行为统计分析、预测新关注、制定推荐方案、
以及预测用户的在线时段。

本仓库是参赛时的完整求解代码。

---

## 一、四个问题与解法

| 问题 | 要求 | 本仓库的解法 | 对应脚本 |
| --- | --- | --- | --- |
| 问题 1 | 基于历史交互数据预测博主的新增关注 | 逐博主训练 **BiLSTM**，用过去数日的互动序列预测下一日新增关注数，输出 Top-N 排名 | `problem_a.py` |
| 问题 2 | 结合附件 2，预测用户 7.22 的**新关注行为** | **LSTM + 集成学习**（随机森林 / 梯度提升）做二分类，特征含用户—博主交互特征；训练样本不足时回退到规则方法 | `problem_b.py` |
| 问题 3 | 制定推荐方案，提升用户与博主的互动量 | 以互动数（点赞 + 评论 + 关注）为目标做候选排序 | `utils.py` 特征工程 + `problem_b.py` |
| 问题 4 | 预测指定用户在 7.23 是否在线及推荐时段 | 按 24 个小时段的用户活跃分布做**时段行为分析** | `探索性分析.py` |

另有一个不依赖深度学习的备选解法：**时间衰减加权模型** —— 用 `0.85^(距今天数)` 作为权重，
取每位博主最近 5 天非零数据加权平均，直接外推下一日热度（`FACT动态预测.py`）。
在数据稀疏、深度模型训练不充分的场景下，这个朴素模型反而是更稳的 baseline。

## 二、目录结构

```
wuyi-mcm-2025-c-social-media/
├── src/
│   ├── config.py           # 数据路径配置（数据不入库，见下）
│   ├── 数据预处理.py         # 构建「博主 × 日期」行为统计表
│   ├── utils.py            # DataProcessor：数据加载与特征工程
│   ├── problem_a.py        # 问题 1：BiLSTM 预测博主新增关注
│   ├── problem_b.py        # 问题 2：LSTM + 集成学习预测用户新关注
│   ├── FACT动态预测.py       # 备选解法：时间衰减加权
│   └── 探索性分析.py         # 问题 4：用户活跃时段分析
├── data/                   # 放竞赛附件（不入库）
├── docs/                   # 赛题
└── requirements.txt
```

## 三、数据

**附件数据没有放进仓库** —— 附件 1 约 70 MB、附件 2 约 13 MB，放进 Git 会让 clone
变得非常慢。请从竞赛官方渠道取得后，放到仓库根目录的 `data/` 下：

```
data/
├── 附件1 (Attachment 1).csv
└── 附件2 (Attachment 2).csv
```

也可以放到别处，用环境变量指过去：

```bash
set MCM_DATA_DIR=D:\some\where        # Windows
export MCM_DATA_DIR=/some/where       # Linux / macOS
```

路径统一在 `src/config.py` 里定义，**代码中没有硬编码的绝对路径**。

## 四、运行

```bash
pip install -r requirements.txt

cd src
python 数据预处理.py        # 先生成 博主行为统计.csv
python problem_a.py        # 问题 1
python problem_b.py        # 问题 2
python 探索性分析.py        # 问题 4
```

> `problem_a.py` / `problem_b.py` 依赖 TensorFlow，逐博主训练模型比较耗时，
> 有 GPU 会自动启用显存按需增长。
